# DXF models that do not import correctly yet #

Same semantics as `models\STEPfile-future\` and `models\IGESfile-future\`, for the
`DxfImportFuture` fixture (`[Explicit]`). Baselines here describe the wanted result, not the
current one; a model that comes up green has been fixed — move it and its `.expected.txt` into
`models\DXFfile\`. Use `MX_DXF_REGEN_DRYRUN=1` to look without writing.
