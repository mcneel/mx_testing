# Models that do not survive a DWG export round trip yet #

Same semantics as the STEP/IGES/DXF `-future` folders, for the `DwgExportFuture` fixture
(`[Explicit]`). Baselines here describe the wanted result, not the current one; a model that
comes up green has been fixed - move it and its sidecar into the verified folder. Use
`MX_DWGEXPORT_REGEN_DRYRUN=1` to look without writing.
