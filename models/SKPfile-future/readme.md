Same semantics as the other `-future` folders, for the `SkpImportFuture` fixture (`[Explicit]`).
Baselines state the wanted result, not the current one; a model that comes up green has been
fixed - move it and its sidecar into the verified folder. Use `MX_SKP_REGEN_DRYRUN=1` to look without writing.
