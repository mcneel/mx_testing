# SketchUp import and export tests - how they work, and how to add one

**Scope:** the SketchUp tests in the `FileIO` project (`FileIO\Skp\`). Ninth format on the
shared pattern: fixtures `SkpImport`/`SkpExport` (+ `[Explicit]` `-future`/`-large`), folders
`models\SKPfile*`, extension `.skp`, namespaces `MX_SKP_*` / `MX_SKPEXPORT_*`.

## SketchUp-specific behaviour worth knowing

**Both directions have real APIs with options** - `FileSkp.Read` and `FileSkp.Write` - which puts
SKP with STL and DXF rather than with 3MF and glTF, whose read sides take nothing. The import side
pins all of `FileSkpReadOptions` explicitly rather than inheriting machine state.

**SketchUp is a surface modeller.** Everything is faces and edges, so Rhino's breps arrive as
meshes, and curves arrive as edges or not at all depending on the reader's `ImportCurves` option
(pinned off by default). `MaxAngle` governs how finely curved surfaces are tessellated on the way
out, which is why the corpus includes a cylinder rather than only boxes.

**⚠ The `Version` write option does not reach the writer.** `skp-2014.skp` is written with
`Version = SketchUp2014` and `skp-box.skp` with the 2021 default, and **both files declare format
version 25** - the SketchUp SDK's own current format. The option is pinned in the sidecar as a
request, the same way IGES and DXF pin theirs, so the day it starts working every baseline diffs
loudly. The structural check deliberately does **not** assert the pinned version against the
header: doing so would leave the suite permanently red on a defect it has already recorded.

## The structural checks

A .skp opens with a fixed signature, and the checks walk it:

- the `FF FE FF` marker, then `SketchUp Model` as UTF-16LE;
- a second marker, a length byte, and that many UTF-16LE characters of version string;
- the version string wrapped in braces and parsing as `major.minor(.build)`, with a plausible
  major number;
- enough bytes after the header that the file is not a header and nothing else.

## The corpus

Generated by `FileIO\Skp\AuthorSkpCorpus.cs`: a closed mesh box, a brep and cylinder that the
writer must tessellate, two bodies on named layers (SketchUp carries layers, unlike STL), and the
2014-version write that exposed the dead `Version` option.

## Running

```bash
MSBuildEnableWorkloadResolver=false dotnet test FileIO/FileIO.csproj -f net48 --no-build --filter "FullyQualifiedName~FileIO.SkpImport"
MSBuildEnableWorkloadResolver=false dotnet test FileIO/FileIO.csproj -f net48 --no-build --filter "FullyQualifiedName~FileIO.SkpExport"
```
